محصولات دسته‌بندی‌ها نظرات کامنت‌ها گفتگوها لیست علاقه‌مندی‌ها تحلیل‌ها تنوع محصولات تصاویر ویژگی‌ها سیستم

مستندات API مدیریت محصولات

این مستندات شامل تمامی API‌های موجود برای مدیریت محصولات، دسته‌بندی‌ها، نظرات، گفتگوها و تحلیل‌ها می‌باشد.

محصولات

GET
دریافت لیست محصولات

دریافت لیست محصولات با قابلیت صفحه‌بندی

آدرس:
/products
پارامترهای اختیاری:
  • page: شماره صفحه (پیش‌فرض: 1)
  • limit: تعداد آیتم در هر صفحه (پیش‌فرض: 10)
POST
ایجاد محصول جدید

ایجاد یک محصول جدید در سیستم

آدرس:
/products
بدنه درخواست:
{
    "name": "نام محصول",
    "description": "توضیحات محصول",
    "price": 100000,
    "category_id": 1,
    "metadata": {
        // اطلاعات تکمیلی محصول
    }
}
GET
دریافت محصول با شناسه

دریافت اطلاعات یک محصول با استفاده از شناسه

آدرس:
/products/{id}
POST
به‌روزرسانی گروهی محصولات

به‌روزرسانی همزمان چندین محصول

آدرس:
/products/bulk-update
بدنه درخواست:
{
    "type": "update",
    "data": [
        // آرایه‌ای از محصولات برای به‌روزرسانی
    ],
    "options": {
        "batchSize": 1000,
        "concurrency": 5,
        "retryAttempts": 3,
        "retryDelay": 1000
    }
}
GET
جستجوی محصولات

جستجوی محصولات با استفاده از متن

آدرس:
/products/search/document
پارامترهای جستجو:
  • query: عبارت جستجو

    "rating": 5,
    "content": "متن نظر"

        },
    },
    "cache": {
        "enabled": true,
        "warming": {
            "lastRun": "زمان آخرین اجرا",
            "status": "وضعیت"
        }
    }
}
