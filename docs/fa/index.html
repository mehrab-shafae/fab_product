مستندات API مدیریت محصولات

این مستندات شامل تمامی API‌های موجود برای مدیریت محصولات، دسته‌بندی‌ها، نظرات و تحلیل‌ها می‌باشد.

محصولات

GET
دریافت لیست محصولات

دریافت لیست محصولات با قابلیت صفحه‌بندی و فیلتر

آدرس:
/products
پارامترهای اختیاری:
  • page: شماره صفحه (پیش‌فرض: 1)
  • limit: تعداد آیتم در هر صفحه (پیش‌فرض: 10)
  • category_id: فیلتر بر اساس دسته‌بندی
  • min_price: حداقل قیمت
  • max_price: حداکثر قیمت
POST
ایجاد محصول جدید

ایجاد یک محصول جدید در سیستم

آدرس:
/products
بدنه درخواست:
{
    "name": "نام محصول",
    "description": "توضیحات محصول",
    "price": 100000,
    "category_id": 1,
    "metadata": {
        // اطلاعات تکمیلی محصول
    }
}

دسته‌بندی‌ها

GET
دریافت ساختار درختی دسته‌بندی‌ها

دریافت ساختار سلسله مراتبی دسته‌بندی‌ها

آدرس:
/categories/tree

نظرات

POST
ثبت نظر جدید

ثبت نظر جدید برای یک محصول

آدرس:
/products/{product_id}/comments
بدنه درخواست:
{
    "user_id": "شناسه کاربر",
    "comment": "متن نظر",
    "rating": 5
}

تحلیل‌ها

GET
تحلیل محصول

دریافت اطلاعات تحلیلی یک محصول

آدرس:
/products/{product_id}/analytics

جستجو

GET
جستجوی پیشرفته

جستجوی محصولات با قابلیت‌های پیشرفته

آدرس:
/products/search
پارامترهای جستجو:
  • q: عبارت جستجو
  • category: فیلتر بر اساس دسته‌بندی
  • price_range: محدوده قیمت
  • sort: مرتب‌سازی نتایج
